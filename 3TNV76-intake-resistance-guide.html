0. 先把物理量说清楚

测点在进气歧管、相对大气的压差，工程上称为进气阻力 （intake depression / restriction）：

Δp(t) = patm − pmanifold(t) 式 (1)　瞬时进气阻力

瞬时值一定可以拆成直流和交流两部分：

Δp(t) = Δpmean + Δpac(t) 式 (2)　平均值 + 进气脉动
关键结论
你看到的正弦波就是 Δpac(t)。柴油机没有节气门，3TNV76 歧管容积又小，这个脉动会非常明显。 有效进气阻力是 Δpmean（正弦的中线），不是峰值，也不是把整段波形直接当有效值。

1. 波形频率和什么有关？

主频几乎只由转速、缸数、冲程数决定，与负荷、滤清器脏不脏关系很小。

四冲程每缸每两转进气一次。三缸均匀点火间隔为 240°CA，因此进气事件频率是 1.5 阶：

fp = i τ · n 60 = 3 2 · n 60 = 1.5 × n 60 式 (3)　进气脉动主频（单位：Hz）

其中：i = 3（缸数），τ = 2（四冲程）， n 为发动机转速（r/min）。 也可写成更方便的现场公式：

fp = n 40 ，　Tp = 40 n 式 (4)　3 缸四冲程专用：频率与周期

对应本次试验转速：

转速 n 曲轴 1 阶　n/60 进气主频（1.5 阶） 2 倍频（3 阶） 脉动周期 Tp
1300 r/min 21.7 Hz 32.5 Hz 65.0 Hz 30.8 ms
1800 r/min 30.0 Hz 45.0 Hz 90.0 Hz 22.2 ms
2350 r/min 39.2 Hz 58.8 Hz 117.5 Hz 17.0 ms
采样率是否足够
1000 Hz 采样完全够用：2350 r/min 时每个脉动周期大约 17 个点，Nyquist 频率为 500 Hz，远高于 58.8 Hz 主频。 若要看气门开启瞬间的尖峰或管道高频反射，1000 Hz 才偏紧（该转速下约每点 14°CA）。

1.1 为什么看起来像正弦，而不是方波或尖脉冲？

  1. 三缸进气相位均匀。 进气门开启角一般 220°–250°CA，与 240° 间隔接近，三缸进气几乎首尾相接，时域上接近连续谐波，而不是单缸那种孤立负压坑。
  2. 歧管容积起低通作用。 容积是气容，滤清器/接管是气阻，高次谐波被衰减，剩下 1.5 阶基波，波形就圆成正弦。
  3. 测压管、接头、传感器带宽再滤一层高频。

因此：频率锁转速；波形圆不圆锁进气系统声学/容积滤波。

1.2 频谱里还可能看到什么

  • 3 阶（2 倍进气事件）：气门开、关各打一次压力波。
  • 1 阶：曲轴不平衡、单缸进气不均、某缸气门间隙异常。
  • 与转速无关的峰：进气管 Helmholtz 固有频率。 当 1.5 阶扫过这个固有频率时，幅值会突然变大，转速再升高又落下来。 这是进气阻力幅值随转速非单调变化的常见原因。

Helmholtz 固有频率近似为：

fH = c 2π √ A / (V · Leq) 式 (5)　进气管 Helmholtz 频率。c 为声速，随进气温度变化
数据有效性判据（当场可做）
对原始信号做 FFT，主峰应满足 fp,测 ≈ 1.5 × n / 60。 建议每个工况记录 fp,测 / fp,理。 若偏差大于约 3%，先查转速信号、采样时钟、测点漏气，而不是先怀疑发动机。

2. 波形幅值和什么有关？

幅值（峰峰值或脉动 RMS）和平均进气阻力不是一回事。 平均阻力是直流；幅值是交流。

2.1 平均进气阻力 Δpmean（正弦的中线）

自然吸气柴油机进气质量流量：

ṁa ≈ ρ · Vh · ηv · n 120 式 (6)　四冲程进气质量流量

滤清器 + 管路阻力近似二次型：

Δpmean ≈ k · ṁa2 ρ ∝ k · ρ · ηv2 · n2 式 (7)　平均进气阻力大致随转速平方上升
因素 对平均进气阻力的作用
转速 n 最强，大致按 n² 上升
容积效率 ηv 气门正时、进排气干涉、进气温度
系统阻力系数 k 空滤脏污、弯头、管径、进气口堵塞
空气密度 ρ 大气压、进气温度、海拔
负荷 柴油机基本不节流，负荷影响弱；高负荷时排气背压/残余废气会略改 ηv

2.2 脉动幅值 Δpac（正弦的高低差）

瞬时负压来自活塞下行抽气。单缸进气行程中活塞速度近似：

up ∝ n · sinθ 式 (8)　活塞瞬时速度随曲轴转角变化

脉动幅值主要取决于下列因素：

  1. 转速 / 活塞平均速度。 转速越高，瞬时抽气越猛，压力波越强。因此 2350 r/min 的峰峰值通常明显大于 1300 r/min （除非撞上共振）。
  2. 进气歧管容积（气容）。 容积越大，同样缸内抽气造成的压力波动越小：
    Δp ∼ Δm ρ · Vman 式 (9)　容积越大，脉动越小
    3TNV76 歧管很小，所以正弦幅值会显得“夸张”，这是机型特征，不是测坏了。
  3. 进气管长度、直径、空滤空腔 → 声学共振。 当 1.5 × n/60 ≈ fH 时，幅值会出现一个鼓包。这是进气系统设计问题，不是平均阻力突然变大。
  4. 气门凸轮型线与气门间隙。 开启越陡、重叠越不合适，高次谐波越强，峰峰值越大。 三缸若某一缸间隙异常，1 阶分量会抬起来，波形不再是干净正弦。
  5. 测点位置。 越靠近某缸进气道口，该缸进气行程的局部抽吸越强，幅值越大、波形越不像纯正弦。 越靠近空滤出口/稳压腔，幅值越小、更接近平均值。 同一台机、不同测点，幅值可以差一倍以上，平均值通常差得少。
  6. 负荷。 自然吸气柴油机空气量几乎不随油门变，脉动幅值随负荷变化远小于汽油机。 若负荷一加幅值大变，优先查排气、EGR（若有）、进气管漏气。
  7. 测量链。 测压软管太长、内径太细、接头泄漏、传感器量程过大，都会改变表观幅值（衰减或引入寄生振荡），但主频一般还在。
一句话
频率告诉你“几缸、几冲程、多少转”；幅值告诉你“抽气有多猛、歧管有多小、管长有没有共振、测点靠哪缸”。

3. 如何从正弦原始波形得到有效数据？

测试报告里的“进气阻力”几乎一律是时均值（直流分量），不是峰值。 脉动要另报。不要把正弦波像交流电压那样直接当“有效值”去报进气阻力。

3.1 有效平均进气阻力（主指标）

对长度为 T 的记录：

Δpmean = 1 T ∫0T Δp(t) dt ≈ 1 N Σk=1N Δp[k] 式 (10)　时间平均 = 算术平均

T 必须覆盖整数个进气周期，否则正弦截断会带来偏置。 周期由式 (4) 给出：Tp = 40 / n（秒）。

实用截取长度
每个工况至少取 20–50 个进气周期，更稳妥是 2–10 s 稳态再平均。
例：1300 r/min，Tp = 30.8 ms，取 2 s 大约 65 个周期，足够。

数字滤波等价做法：

  • 低通截止远低于主频，例如 fc = 5–10 Hz（1300 r/min 主频已是 32.5 Hz）。
  • 用零相位 FIR 或 filtfilt，避免相位把均值边缘搞歪。
  • 丢掉滤波器过渡段后再平均。

不要用峰值、峰峰值、或把整段 RMS 当进气阻力。整段 RMS 会把直流和交流混在一起：

pRMS = √ Δpmean2 + Δpac,RMS2 式 (11)　整段 RMS ≠ 进气阻力。空滤是否该换，看的是 Δpmean

3.2 脉动指标（辅指标，建议同时出）

从去直流后的交流分量计算：

Δpac(t) = Δp(t) − Δpmean 式 (12)
指标 定义 用途
峰峰值 ppp max − min 看瞬时极值；对传感器量程、空滤纸板疲劳有意义
脉动 RMS √(Δpac² 的平均) 能量意义；纯正弦时 ≈ ppp / (2√2)
脉动系数 ppp / Δpmean
或 pRMS / Δpmean		 比较不同转速

波形若接近纯正弦，可用下式自检：

ppp ≈ 2√2 · pac,RMS ≈ 2.828 · pac,RMS 式 (13)　正弦关系自检。偏差大，说明有谐波或削波

3.3 推荐处理流程（1000 Hz 原始数据）

  1. 检查单位与极性。 表压真空应为正的进气阻力。确认大气压通道，必要时用绝对压力减当地大气压。
  2. 去坏点。 尖刺、超量程、接头松动造成的掉零。
  3. 转速同步核对频率。 FFT 主峰应等于 1.5 × n / 60。每个工况记一笔 fp,测 / fp,理，作为数据有效性门槛。
  4. 稳态判定。 转速、油门、水温稳定后再截取。可用滑动平均阻力的标准差小于某阈值 （例如 2% 或 0.05 kPa）作为稳态。
  5. 按整数周期截取并算术平均 → 得到该转速的 Δpmean。
  6. 同时输出 ppp、pac,RMS、主频。
  7. 绘制两条曲线：
    • Δpmean = f(n)：空滤/管路阻力特性，应大致随 n² 上升。
    • ppp = f(n)：若某处鼓包，查进气管 Helmholtz 共振。
  8. （可选）曲轴转角域。 1000 Hz @ 2350 r/min 大约每点 14°CA，对气门事件偏粗，但对三缸整机进气阻力已经够。 若以后要看某缸进气道口波形，需要编码器 + 至少 0.5–1°CA 分辨率。

3.4 和台架惯例对齐

发动机性能试验（如 GB/T 18297、ISO 3046 一类）报的进气阻力是 平均进气真空度，常常还规定测点（空滤后、压气机前或歧管规定位置）和允许上限。 空滤本身的阻力特性另有滤清器试验方法，不要和发动机歧管脉动混成一个数。

现场若仪表抖动读不出数，老做法是测压管加阻尼孔/稳压壶。 现在 1000 Hz 数字采样，用数字低通 + 周期平均即可替代机械阻尼，而且能把脉动单独留下来，比稳压壶更完整。

4. 针对 3TNV76 的现场判断

  • 三缸四冲程 → 只认 1.5 阶。 1300 r/min 约 32.5 Hz，2350 r/min 约 58.8 Hz。对得上，数据物理上就成立。
  • 自然吸气、歧管小 → 正弦幅值大是正常的；有效数据仍是中线（平均值）。
  • 平均阻力随转速应大致二次上升；若平均值几乎不变而幅值猛跳，多半是声学共振或测压管共振，不是空滤突然堵死。
  • 若波形从正弦变成明显“一头深一头浅”，查各缸进气门间隙、某缸进气道堵塞、测点是否太贴某一缸口。
