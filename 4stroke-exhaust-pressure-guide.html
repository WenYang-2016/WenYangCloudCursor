0. 排气压力要拆成哪几部分

测点通常在排气歧管、涡轮前（有增压时）或消声器前。瞬时排气压力同样写成直流 + 交流：

pex(t) = pex,mean + pex,ac(t) 式 (1)　平均排气压力（或称排气背压） + 排气脉动

这两个量的物理来源完全不同，不能混成一个“排气压力”去谈负荷。

量 工程含义 主要来源
pex,mean 平均排气背压 排气管、消声器、颗粒捕集器、涡轮的通流阻力；排气质量流量和温度
pex,ac 排气脉动（你看到的波形高低） 每缸排气门打开时的吹下（blowdown）压力波，再叠加活塞上止点排挤阶段

四冲程每一缸的排气过程本身就有两段，所以排气波形往往不像进气那样接近纯正弦：

  1. 吹下阶段（blowdown）：排气门在下止点前打开（EVO，常见 40°–60°BBDC）。 此时缸内压力仍明显高于歧管，燃气以临界或近临界流喷出，形成陡峭的压力脉冲。
  2. 排挤阶段（displacement）：活塞从下止点向上走，把剩余废气推出去。 这一段更接近“活塞泵”，压力较低、较宽。
和进气波形的直观差别
进气是活塞下行抽吸，歧管容积一滤波，三缸均匀叠加后容易变成正弦。 排气先有一次高压喷放，再有一次活塞推挤，频谱里高次谐波更强，时域上更容易看到“尖峰 + 平台”，而不是圆正弦。 测点离排气门越远、消声器容积越大，尖峰会被削圆，看起来又会接近正弦。

1. 频率和什么有关

主频的公式与进气事件频率相同：四冲程每缸每两转排一次，三缸间隔 240°CA，仍是 1.5 阶。

fp = iτ · n60 = 1.5 × n60 = n40 式 (2)　三缸四冲程排气事件主频（Hz）。i = 3，τ = 2

对应 3TNV76 常用转速：

转速 n 排气主频（1.5 阶） 吹下 + 排挤带来的 3 阶 曲轴 1 阶（各缸不均时）
1300 r/min32.5 Hz65.0 Hz21.7 Hz
1800 r/min45.0 Hz90.0 Hz30.0 Hz
2350 r/min58.8 Hz117.5 Hz39.2 Hz

1.1 决定频率的因素（按重要性）

因素对主频的影响说明
转速 n 成正比，最强 主频锁转速。负荷变、喷油量变，主频基本不动。
缸数 i、冲程数 τ 决定阶次 三缸四冲程 = 1.5 阶；四缸四冲程 = 2 阶；六缸 = 3 阶。
排气门开、关各一次 产生 2 倍频（3 阶） 吹下尖峰对应 EVO，排挤对应活塞运动。排气比进气更容易看到 3 阶。
排气管长度、消声器空腔 出现与转速无关的固有频率 当 1.5 阶扫过管道/消声器共振时，幅值鼓包，频率仍是发动机阶次。
负荷、燃烧、空滤 几乎不改主频 只改脉冲强弱和波形尖不尖。
某缸失火、气门间隙异常 抬高 0.5 阶或 1 阶 三缸若一缸不工作，均匀 240° 被破坏，频谱不再干净。

排气管四分之一波长（一端开、一端近似闭）的声学频率：

fpipe = c4L ，　c ≈ √γRTex 式 (3)　排气管固有频率。排气温度随负荷升高，声速 c 也升高，共振转速会略微外移
负荷对“频率”仅有的间接影响
负荷本身不产生新的发动机阶次。但高负荷排气温度高，声速变大，管道共振对应的转速会稍稍升高。 FFT 主峰仍然是 1.5 × n/60，不会变成“负荷频率”。

2. 幅值和什么有关

幅值要分开谈：平均背压的高低，和脉动峰峰值的高低。

2.1 平均排气背压 pex,mean

排气管系阻力仍接近二次型，但排气是热气，体积流量随温度涨得很快：

ṁex = ṁa + ṁf 式 (4)　排气质量流量 = 空气 + 燃油
Δpmean ≈ k · ṁex2ρex ，　ρex = pexRTex 式 (5)　平均背压。k 由管径、弯头、消声器、后处理决定

因此平均背压取决于：

  • 转速：空气质量流量近似正比于 n，平均背压大致随 n² 上升（与进气阻力同类）。
  • 系统阻力 k：消声器堵塞、DPF 积碳、排气管压扁，会整体抬高中线。
  • 排气温度 Tex：密度下降，同样质量流过时体积流量变大，压损增加。
  • 有涡轮时：平均背压主要是涡轮做功需要的膨胀比，和负荷、增压需求强相关。

2.2 脉动幅值 pex,ac（峰峰值或脉动 RMS）

脉动的源头是排气门开启瞬间缸内压力与歧管压力之差：

Δpblowdown ≈ pcyl(θEVO) − pex,mean 式 (6)　吹下压差。这是排气脉动幅值的第一决定量

通过排气门的瞬时质量流（一维准稳态）：

ṁv = Cd A(θ) · pcyl √(R Tcyl) · Ψ(π) 式 (7)　π = pex/pcyl。压差大时经常达到临界流，Ψ 封顶

脉动幅值因此还受这些因素调制：

因素如何影响幅值
缸内 EVO 压力 pEVO 最强。由喷油量、燃烧相位、压缩比、进气量共同决定。负荷一加，这项显著上升。
转速 / 活塞速度 转速高，吹下可用时间变短，瞬时流量更猛；同时下一缸事件更密，脉动叠加更强。
排气门正时与升程 EVO 越早，pEVO 越高（膨胀没做完），脉冲越陡、越强，但指示功会掉。
歧管容积、管长、是否分缸排气 容积大则脉冲被稀释；三缸共用一根歧管时，240° 间隔的脉冲会互相顶。
测点位置 靠近某缸排气口：该缸吹下尖峰极大。消声器后：脉动被滤掉，几乎只剩平均值。
消声器 / 后处理 对平均值是阻力（抬中线），对脉动是低通（削峰）。所以“消声器后幅值小”不等于“发动机排气弱”。

3. 排气压力如何接到缸内燃烧做功

这是把“缸内燃烧”和“管里测到的排气压力”连起来的一条因果链。 排气脉动不是燃烧做功本身，它是做功之后没被膨胀行程抽走、残在燃气里的焓，在排气门打开时泄放到歧管里。

喷油量 mf（负荷） → 放热 Qcomb → 缸压 pcyl(θ)、温度 Tcyl(θ) → 膨胀做功 Wi → 排气门开启时剩余 pEVO、TEVO → 吹下脉冲 pex,ac → 排气管平均背压 pex,mean（再反作用于下一循环泵气损失）

3.1 缸内指示功

一个循环的指示功（活塞顶面气体对活塞做的净功）：

Wi = ∮ pcyl dV ，　IMEP = WiVh 式 (8)　指示平均有效压力。负荷在台架上最终表现为转矩 / BMEP，它来自 IMEP 减去摩擦和泵气
BMEP = IMEP − FMEP − PMEP 式 (9)　BMEP 是你油门/测功机看到的负荷。PMEP 含进排气泵气，排气背压越高，PMEP 越吃功

3.2 燃料能量怎么分

喷进去的燃料化学能，在一个循环里大致分成四块：

mf · Hu · ηcomb ≈ Wi + Qcool + Hexh + Qother 式 (10)　Hu 低热值；Hexh 是排气焓，也就是排气压力/温度脉动的能量来源
  • Wi：活塞真正拿到的指示功。膨胀越充分，这块越大。
  • Qcool：缸壁、缸盖、冷却液带走的热。
  • Hexh：废气离开气缸时仍带着的焓。pEVO、TEVO 越高，这块越大，吹下脉冲越强。
  • Qother：不完全燃烧、辐射、漏气等。

所以：同样多的油，燃烧得越及时、膨胀得越干净，指示功越大，排气脉冲往往越弱；燃烧越晚、EVO 开得越早，指示功越小，排气脉冲越强。 负荷增加时两边都会变：油多了，Wi 和 Hexh 一起涨，排气脉冲还是会变强。

3.3 从燃烧放热到 EVO 缸压

压缩、燃烧、膨胀段，忽略漏气时能量方程可写成：

dQcombdθ − dQcooldθ = p dVdθ + m cv dTdθ 式 (11)　放热一边抬缸压，活塞下行一边把压力“做成功”卸掉

柴油机负荷的本质是 mf。自然吸气机进气量几乎不随油门变，过量空气系数 λ 随负荷下降：

λ = ṁaṁf · Lst 式 (12)　3TNV76 这类自然吸气柴油机：怠速 λ 很高，标定负荷 λ 降到约 1.2–1.6

负荷升高时的缸内后果：

  1. 循环放热增加 → 最高爆发压力 pmax、最高温度上升。
  2. 膨胀比是几何固定的（由压缩比和 EVO 角决定），放热多了，膨胀到 EVO 时剩下来的压力、温度也更高。
  3. 因此 pEVO(高负荷) ≫ pEVO(怠速)。怠速时吹下压差很小，排气波形接近弱正弦；大负荷时吹下是明显尖峰。

若把膨胀近似看成多变过程（只为建立数量级，不是精确循环）：

pEVO ≈ pmax Vpmax VEVO nexp 式 (13)　pmax 随负荷升，VEVO 由凸轮决定。EVO 越早，VEVO 越小，pEVO 越大

3.4 吹下：缸内剩余压力如何变成管里的脉冲

排气门一开，气缸与歧管连通。若 pEVO / pex 大于临界压比（对热废气大约 1.8–2.0），阀喉达到声速，质量流只取决于缸内状态，短时间内把一股高压气体“射”进歧管。 歧管是有限容积，于是出现压力突升，这就是你传感器看到的脉冲前沿。

dpmandt ≈ RTexVman (ṁv − ṁpipe) 式 (14)　歧管容积越小，同样吹下质量造成的压力跳变越大。3TNV76 排气歧管小，脉冲会很“狠”

吹下结束后，缸压已经落到接近歧管压力，此后主要靠活塞上行排挤。排挤段的瞬时流量近似：

ṁdisp ≈ ρex · Apiston · up(θ) ，　up ∝ n · sinθ 式 (15)　排挤段更像进气的“镜像”，和转速关系大，和燃烧关系相对小

因此高负荷排气波形 = 强吹下尖峰（跟燃烧、负荷有关）+ 较宽的排挤鼓包（跟转速、活塞运动有关）。 低负荷时吹下几乎看不见，只剩排挤，波形会圆一些，有点像进气正弦。

3.5 反过来：排气压力也会吃掉一部分做功

泵气损失里，排气冲程活塞要克服排气背压：

Wexh,pump = ∫BDCTDC pex(θ) dV 式 (16)　平均背压越高、脉冲在排挤段叠加越高，活塞越费劲，BMEP 越低

三缸特别要小心相位干涉：

  • 点火间隔 240°CA。
  • 排气门开启角往往 230°–260°CA。
  • A 缸吹下的高压波，正好可能撞上 B 缸还在往外排的排挤段。

结果是 B 缸扫气变差、残余废气增加、下一循环指示功下降。 所以排气压力不仅是“燃烧的结果”，也会在下一循环变成“燃烧的边界条件”。 自然吸气三缸机的低速大扭矩区，这种脉冲干涉经常能在排气压力和油耗上同时看到。

3.6 燃烧相位：同样负荷，排气脉冲可以不一样

这是测试时最容易误判的点。负荷（转矩）相同，并不等于排气幅值相同。

燃烧状态 指示功 Wi EVO 剩余焓 排气脉动
喷油及时，CA50 合适 高 较低 相对较弱、较圆
喷油过晚、后燃多 掉 高（排气温度也高） 尖峰更强，平均背压也升
EVO 开得过早 膨胀没做完，Wi 掉 pEVO 高 吹下极强
某缸失火 该缸 Wi ≈ 0 该缸几乎无吹下 1.5 阶减弱，1 阶出现
一句话对准“做功”
台架上的负荷（转矩 / BMEP）来自缸内净指示功减去摩擦和泵气。 排气脉动幅值来自膨胀结束时还没做成功的那部分缸压。 所以：负荷↑ → 通常排气脉动↑；但排气脉动↑ 不一定等于负荷↑，也可能是燃烧变晚、排气门过早或排气管堵了。

4. 排气压力和发动机负荷是否有关

有关，而且对自然吸气柴油机来说，排气脉动幅值是少数几个“对负荷敏感、对进气不敏感”的管路信号之一。

4.1 先把“负荷”说清楚

柴油机油门改变的是喷油量 mf，不是节气门。3TNV76 没有进气节流。 因此同一转速下：

  • 进气质量流量几乎不变 → 进气阻力平均值、进气脉动幅值随负荷变化很弱（前文结论）。
  • 循环放热随 mf 变 → pmax、pEVO、Tex 随负荷变 → 排气脉动幅值随负荷变。

4.2 同一转速下，负荷对三个排气量的影响

排气量 与负荷的关系（NA 柴油，固定转速） 原因
主频 fp 基本无关 只锁转速和缸数
脉动峰峰值 / 吹下尖峰 强相关，随负荷明显上升 pEVO 随喷油量和放热增加
平均背压 pex,mean 中等相关，通常缓升 ṁf 只占排气质量的 3%–6%，但 Tex 可从怠速一两百摄氏度升到满载四五百摄氏度，体积流量和消声器压损上升
排气温度 Tex 强相关 最直接的负荷热信号，常比压力平均值更线性

4.3 为什么质量流量几乎不变，压力脉动却对负荷很敏感

这是柴油机特有的逻辑。自然吸气柴油机每循环吸入的空气差不多，多喷的油只增加几个百分点的排气质量。 但多喷的油把燃气温度、压力在膨胀末期抬上去了。吹下是压力驱动的射流，不是“多出来那点质量”在起作用。

数量级概念（同一转速）：

  • 怠速 / 极小负荷：λ 很大，pEVO 可能只略高于大气，吹下很弱。
  • 中等负荷：吹下开始清晰，峰峰值明显大于进气脉动。
  • 标定 / 大负荷：pEVO 可达数个大气压量级（取决于 EVO 角和燃烧），歧管脉冲峰峰值远大于平均背压本身。

所以如果你在排气歧管上用 1000 Hz 采样，会看到： 中线（平均值）随负荷慢慢抬；振幅随负荷明显变大；频率不动。

4.4 不同机型，结论不能照搬

机型 负荷如何实现 排气压力 vs 负荷 进气压力 vs 负荷
自然吸气柴油（3TNV76） 只改喷油量 脉动强相关；平均中等相关 很弱（前文）
增压柴油 喷油 + 增压随负荷升 涡前平均压力、脉动都强相关（涡轮要吃焓） 进气压力（增压）也强相关
节气门汽油机 节气门改进气量 相关（进气少则燃烧少，pEVO 低） 强相关（进气歧管真空就是负荷计）

4.5 不能把排气幅值直接当负荷计

虽然方向上“负荷大 → 排气脉冲大”，但中间还有几层混淆：

  1. 转速耦合。 必须先固定转速再比幅值。转速一变，1.5 阶频率和活塞排挤强度都变。
  2. 燃烧相位。 同样转矩，喷油推迟会让排气更热、脉冲更尖。
  3. 排气阻力。 消声器堵了会抬平均背压，脉冲形状也变，看起来像“负荷大了”。
  4. 测点。 歧管口和消声器后完全不是同一个信号。
  5. 冷却和水温。 冷机后燃多，排气温度和脉冲都会偏大。
正确用法
要用排气压力判断负荷，应当：固定转速 → 用脉动峰峰值或 1.5 阶幅值，而不是只用平均值 → 先用测功机做一条标定曲线（转矩 vs 排气脉动）。 没有这条标定，排气压力只能做定性：比怠速大多了，说明在带载。

6. 若你去测排气压力，有效数据怎么取

处理原则与进气相同，但解释相反：进气看中线做阻力；排气要同时看中线和振幅，因为振幅才带负荷信息。

  1. 核对 FFT 主峰是否等于 n/40。对不上先查转速和采样。
  2. 按整数个排气周期做算术平均，得到 pex,mean（背压）。 周期 Tp = 40/n 秒。建议每个工况 2–10 s。
  3. 去直流后算峰峰值 ppp 和脉动 RMS。高负荷时 ppp 往往明显大于 2.828 × RMS，说明不是纯正弦，这是吹下尖峰的正常结果，不要按进气那套正弦自检去判废。
  4. 固定转速、改变测功机负荷，分别画 pex,mean(负荷) 和 ppp(负荷)。前者缓升、后者陡升，就和本文一致。
  5. 有条件再加排气温度。Tex 和 ppp 一起看，比单看平均背压更能对上燃烧负荷。
可带到台架上的判断口诀
频率认转速；中线认排气管堵不堵；振幅认燃烧和负荷；尖不尖认 EVO 和燃烧早晚。 三缸机再加一条：相邻缸脉冲会互相顶，低速大负荷时幅值和残余废气都会变差。
