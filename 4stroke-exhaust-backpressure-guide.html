四冲程内燃机排气背压
平均值、排气温度与发动机负荷

本文只讨论排气背压（瞬时波形的中线 / 时间平均值），不把脉动峰峰值当成背压。对象按洋马 3TNV76：三缸、四冲程、自然吸气柴油机。

核心量：pex,mean（平均排气背压）
对照：进气阻力看中线；排气脉动另文处理
关键链：负荷 → 排气温度 → 体积流量 → 平均背压
限定：同一转速下这条链才是主因
可以这么理解，但要收窄范围： 同一转速下，自然吸气柴油机的平均排气背压，很大程度上是被排气温度带着走的。 负荷升高 → 喷油增多 → 排气温度升高 → 废气变稀、体积流量变大 → 流过同一套排气管和消声器时，平均背压升高。 转速一变，质量流量才是中线升高的大头。平均背压随负荷升得比较温和，不要把它当成最灵敏的负荷计。

1. 排气背压到底指哪一个数

排气歧管上采到的瞬时压力一定在跳。它必须拆成：

pex(t) = pex,mean + pex,ac(t) 式 (1)　中线 = 背压；交流 = 排气脉动。本文只讨论中线

工程上说的排气背压，指的是相对大气的平均压差，也就是正弦或脉冲波形的中线：

Δpback = pex,mean − patm = 1T ∫0T [ pex(t) − patm ] dt 式 (2)　对外报告的排气背压。T 必须覆盖整数个排气周期
不要用峰值当背压
吹下尖峰可以比中线高很多。峰值反映排气门刚打开时缸内剩余压力，跟负荷、燃烧相位关系更强，但那不是排气管通流阻力意义上的背压。 消声器是否该换、管路是否堵塞，看的是 Δpback（平均值）。

对三缸四冲程，排气事件频率仍是 1.5 阶，只用来保证平均时截取了整数周期，它本身不是背压的大小：

fp = n40 ，　Tp = 40n 式 (3)　单位：Hz 与秒。1300 r/min → 32.5 Hz；2350 r/min → 58.8 Hz

2. 平均背压由哪几项决定

排气管、弯头、消声器对稳态通流近似二次型阻力。热气的密度随温度变，所以必须把密度写进去：

ṁex = ṁa + ṁf 式 (4)　排气质量流量 = 空气 + 燃油
Δpback ≈ k · ṁex2ρex ，　ρex = pexR Tex 式 (5)　k 由管径、弯头、消声器、后处理决定，堵塞时 k 变大

把密度代进去，平均背压的结构就清楚了：

Δpback ∝ k · ṁex2 · Tex 式 (6)　同一套管路：质量流量的平方 × 排气温度。这是本文全部讨论的出发点
因素 符号 怎样改变平均背压
系统阻力 k 消声器积碳、管路压扁、弯头过多 → 中线整体抬高。与负荷无直接关系。
质量流量 ṁex 自然吸气机主要由转速决定（空气量 ∝ n）。燃油只占百分之几。
排气温度 Tex 同一转速下，这是负荷能明显推动平均背压的主要通道。
当地压力 pex 密度里有 p，背压升高会略微把密度补回来，是弱的负反馈，通常可忽略。

3. 为什么平均值会跟排气温度有关

消声器和排气管“看见”的不是质量有多少公斤，而是体积流量有多大。 同样 1 kg 的废气，温度高就膨胀得更厉害，穿过同一截面积时速度更高，压损按速度平方上升。

V̇ex = ṁexρex = ṁex · R Texpex 式 (7)　体积流量随绝对温度线性增加

因此：质量流量几乎不变时，温度从 200 °C 升到 500 °C（绝对温度约 473 K → 773 K），体积流量大约增加到 1.6 倍，二次型压损大约增加到 2.6 倍量级。这就是“温度把平均背压抬起来”的数量级来源。

同一转速、自然吸气柴油机
进气量几乎不随油门变，多喷的油只增加 3%–6% 的排气质量。 质量项几乎不动，温度项动得很明显。 所以：这一转速下平均背压随负荷变化，主要就是排气温度在起作用。

4. 排气温度和负荷的关系

柴油机油门改变的是喷油量 mf，不是节气门。负荷升高，循环放热增加，膨胀结束时燃气仍带着更高的焓，排气就更热。

mf · Hu · ηcomb ≈ Wi + Qcool + Hexh + Qother 式 (8)　没做成指示功、也没被冷却带走的部分，进入排气焓 Hexh，表现为 Tex
负荷升高（转矩 / BMEP ↑） → 喷油量 mf ↑ → 过量空气系数 λ ↓ → 膨胀末期 TEVO、焓 ↑ → 排气温度 Tex ↑
工况变化 Tex 怎么变 说明
同一转速，负荷升高 明显升高 主通道。怠速一两百摄氏度，到标定负荷可到四五百摄氏度量级（视机型和测点）。
同样负荷，喷油偏晚 / 后燃 也会升高 指示功减少，排气焓增加。这时温度高并不等于负荷更大。
空滤堵、进气量不足 往往升高 λ 变浓，燃烧更热。不是负荷变了，是进气边界变了。
冷却不良、水温过高 偏高 Qcool 变小，更多热进排气。
负荷和温度是强相关，不是一一对应
可以说“负荷高，排气温度通常高”。 不可以说“温度高就一定是负荷大”。喷油正时、空燃比、冷却都会单独推动 Tex。

5. 负荷 → 温度 → 背压，这条链何时成立

把式 (6) 和上一节合在一起，就是讨论中的因果链：

负荷 ↑　→　Tex ↑　→　ρex ↓　→　体积流量 V̇ex ↑　→　Δpback ↑

这条链成立，但必须同时满足下面的范围。

5.1 成立条件

  • 转速基本不变。 一比不同转速，质量流量按 n 变，中线按近似 n² 变，温度不再是第一原因。
  • 自然吸气、用油量控制负荷。 3TNV76 属于这一类。进气几乎不节流，负荷主要通过温度影响背压。
  • 测的是管系通流阻力（歧管到消声器出口），不是涡轮前压力。有涡轮时，平均压力主要是涡轮要吃焓、要建立膨胀比，不能理解成“气热了所以管子堵”。
  • k 没有同时在变。 消声器没有突然堵塞，管路没有被改掉。

5.2 同一转速下各量对负荷有多灵敏

量 同一转速下随负荷 原因
排气温度 Tex 明显上升 喷油量和排气焓的直接热信号
平均背压 Δpback 中等、缓慢上升 质量几乎不变，只靠温度把体积流量抬上去；k 小的时候绝对增量不大
排气脉动峰峰值 明显上升（本文不把它当背压） 排气门开启时缸压 pEVO 升高，那是另一条链
排气质量流量 几乎不变（只多了燃油那几个百分点） 自然吸气柴油机的特征
对“背压高是因为温度高”的准确说法
同一转速下：负荷高 → 温度高 → 平均背压偏高，方向正确。 平均背压是这条链上比较钝的一个结果。要看负荷，排气温度通常比平均背压更灵敏；平均背压更适合判断排气管系堵不堵。

5.3 何时这条链解释不了

现象 不宜再用“温度导致背压”解释
平均背压升很多，温度没有按比例升 优先查 k：消声器积碳、管路堵塞、测点漏气或取错位置
转速从 1300 变到 2350，中线明显抬高 主因是空气质量流量，不是负荷温度
同样转矩，喷油变晚，温度和背压都升 燃烧相位变了，不是负荷变大
涡轮增压机的涡前平均压力随负荷猛升 涡轮通流/膨胀比，不是消声器管阻的温度项

6. 不要把背压和脉动、转速效果混在一起

把三个常见混淆并排写清楚，避免把“排气压力”一个词用成三种意思。

比较 平均排气背压 Δpback 排气脉动幅值 转速升高带来的中线升高
波形上 中线 高低差 / 吹下尖峰 也是中线，但是换转速造成的
物理来源 管系阻力 × 体积流量 排气门开启时的缸内剩余压力 空气质量流量随 n 增加
与温度 同一转速下主要靠温度 间接（热气声速、密度），主因不是温度 温度会变，但不是主因
与负荷 中等相关，缓升 强相关 应先固定负荷再谈转速，或固定转速再谈负荷
台架用途 判断消声器/管路是否堵塞 看燃烧和负荷（需标定） 进排气阻力随转速的平方特性

和进气阻力对照（都是“平均值 / 中线”）：

进气阻力平均值 排气背压平均值
随转速 大致 ∝ n²（空气流量） 大致 ∝ n²，再乘温度项
同一转速随负荷 很弱（柴油机不节流） 中等（主要通过 Tex）
对外报告 报中线 同样报中线，不要报峰值

7. 台架上如何得到有效的排气背压

  1. 测点。 报告背压必须写清位置：排气歧管、消声器前或消声器后。越靠后，脉动越小，平均值越接近“管系阻力”本身。
  2. 极性与大气压。 背压是相对当地大气压的正压。绝对压力传感器要减去当时大气压。
  3. 按整数周期取平均。 用式 (3) 的 Tp = 40/n，每个工况取 2–10 s 稳态再算术平均，得到 Δpback。 低通截止远低于主频（例如 5–10 Hz）再平均，效果等价。
  4. 同时记转速、负荷、排气温度。 没有这三项，平均背压无法解释。建议每个转速做一条 Δpback = f(负荷)，并叠一条 Tex = f(负荷)。
  5. 判读。
    • 同一转速，负荷升，Tex 升、Δpback 缓升 → 符合本文的温度链。
    • 同一转速，Tex 几乎不变而 Δpback 猛升 → 查 k（堵塞）。
    • 负荷、温度都变了不多，只是转速升了、中线升了 → 质量流量，不是负荷温度。
可以带到现场的四句话
1. 排气背压 = 瞬时压力的时间平均值，不是峰值。
2. 同一转速下，平均背压很大程度上跟排气温度有关。
3. 排气温度跟负荷强相关，所以负荷高往往平均背压也偏高。
4. 转速变了先看流量；中线单独猛升而温度不动，先看排气管堵不堵。
